Minecraft: Rust Edition — source test build
==========================================

This is an unofficial fork of Horizon. It is not approved by or associated
with Mojang or Microsoft. The original MIT license is included in LICENSE.
This folder contains no Minecraft game jars, textures or sounds. Preparation
reads your own Minecraft installation. Gameplay runs in Rust.

Fabric and Java mod code do not run in this build. Basic online login and
signed chat have passed local server checks, but full Java compatibility
has not been established.

Start with the launcher
  Open Minecraft Rust Edition.app on macOS, or run horizon-launcher
  (horizon-launcher.exe on Windows). In Versions, choose this unpacked
  build folder under Local builds. Select the installed local build,
  prepare its files from your Minecraft installation, then press Play.
  START-HERE.md explains the source-build setup and account import.

  The current game pin is Minecraft Java Edition 26.3. Preparation needs
  a Java 25 JDK with javac, which compiles the included preparation tools.
  The official launcher's installed runtime can supply it when available.

  For online play, use Import launcher session in Settings. On macOS,
  you may need to start your official Minecraft installation once so the
  importer can read the selected account's running game session.

  Project and future releases:
  https://github.com/calebtrueman/minecraft-rust-edition
  This is a source test package, not a signed release.

Prepare by hand
  From this folder, with Java 25 and Minecraft 26.3 installed:
    ./horizon-prepare --prepare --server-jar PATH/TO/server.jar
    ./horizon-prepare sounds
  Add --minecraft-dir PATH if the game is installed elsewhere. On Windows,
  use horizon-prepare.exe. Then run horizon-client (horizon-client.exe on
  Windows). These internal program names have not changed yet.

Controls: mouse look, WASD move, Space jump, Left Shift sneak, Left Ctrl
sprint, left click break, right click place/use, 1-9 or scroll for the hotbar,
E inventory, Q drop, F1 hide the HUD, F3 debug, Esc pause.

Scripts and AI agents
  horizon-ctl, in this folder, plays the game from a terminal or a script:
    ./horizon-ctl launch --world Test --wait     (horizon-ctl.exe on Windows)
    ./horizon-ctl state
    ./horizon-ctl help                           lists every command
  horizon-ctl mcp is an MCP server for AI agents (stdio; add it to your MCP
  client as the command horizon-ctl with the argument mcp). It finds the game
  beside it or the version the launcher installed.

Running a server
  horizon-server, in this folder, hosts a server with this game as its engine,
  using the resources prepared above:
    ./horizon-server --dir my-server init     the EULA, world, seed, port, who may join
    ./horizon-server --dir my-server start    in the background; also stop, restart
    ./horizon-server --dir my-server status   TPS, MSPT, players, RAM and CPU
    ./horizon-server --dir my-server cmd list
    ./horizon-server --dir my-server backup   also backups, restore
    ./horizon-server --dir my-server service install   start it at boot or login
  Its settings are in my-server/server.toml. ./horizon-server help lists every
  command; docs/server.md in the repository has the details.
